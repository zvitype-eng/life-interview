# Subject Notes — between-session inbox

The interview runs asynchronously over weeks. This file lets the subject live with a question between turns: add to a prior answer, surface a memory unprompted, or flag a correction. Freeform.

How it is folded in:
- An addition to an answered question is appended to that answer in `log.md` through a normal turn.
- A correction goes to `turns.md`.
- A new story goes to `volunteer-log.md` verbatim.
